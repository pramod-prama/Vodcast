# 🚀 Quick Start Guide

## Step 1: Start the API Server
```bash
# In the main project directory
python simple_api_server.py
```
✅ API should be running at `http://localhost:7860`

## Step 2: Start the Frontend
```bash
# In the frontend directory
cd sadtalker-frontend-demo
npm install
npm start
```
✅ Frontend should open at `http://localhost:3000`

## Step 3: Test the Demo

### 🎯 Quick Test Flow:

1. **Health Check** - Verify API is running
2. **Create Job** - Upload image + audio files
3. **Monitor Progress** - Watch real-time updates
4. **Download Video** - Get the generated result

### 📁 Use Sample Files:
- **Image**: `examples/source_image/people_0.png`
- **Audio**: `examples/driven_audio/bus_chinese.wav`
